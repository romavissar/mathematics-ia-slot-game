# IA bankroll slot (Next.js)

Interactive demo of the Math AI HL IA bankroll model: net changes **−1**, **+1**, **+19**, **+99** with the probabilities from the Python reference scripts in the parent folder.

## Run locally

```bash
cd slot-ia-app
npm install
npm run dev
```

Open the URL shown in the terminal (usually `http://localhost:3000`).

```bash
npm run build
```

Production build for deployment.
